Brainrot 3D METEOR is a Roblox 3D game built with Rojo and Luau: meteors crash into a fenced arena and spawn collectible brainrots across six rarities (Common, Rare, Epic, Legendary, Mythic and Secret), each with its own price, income per second and spawn color. Players start with 550 money, buy brainrots to build passive income, lock their base for protection, steal from rivals on a cooldown, and rebirth at 100,000 money for a permanent 1.25x multiplier, with a client HUD and camera orbit presenting the action.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

This runs the entry as the grader does, writing the submission to `out/` instead of `/output`.
